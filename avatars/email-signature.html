Install in Gmail

  1. Open this page in a browser → click Copy HTML.
  2. Gmail → ⚙ Settings → See all settings → General → Signature.
  3. Paste into the signature editor. Gmail will preserve the HTML.
  4. Set as default for For new emails and On reply/forward.
  5. Send a test to yourself — verify the four avatars load and the divider renders.
