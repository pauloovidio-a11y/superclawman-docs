Privacy Policy

Effective 13 August 2026 · Last updated 13 August 2026

SuperClawman is a personal automation system run by one person for his own use. It is not a product, it has no user accounts, and it collects nothing from visitors to this website.

01Who operates this

SuperClawman is built and run by Paulo Ovídio on his own machines and his own accounts. It is not a company and has no customers. Nobody else is given access to the data described below.

02This website

superclawman.ai is a set of static pages. It runs no analytics, no advertising, no tracking pixels, and no third-party scripts of that kind. It sets no cookies of its own and does not build visitor profiles.

The site loads web fonts from Google Fonts and images from GitHub Pages. Those providers will see the requesting IP address as a normal consequence of serving a file, as they would for any website. Standard server logs may be retained by the hosting provider (Cloudflare Pages) for security and reliability.

03eBay integration

SuperClawman connects to the eBay API to help list personal used items on the operator's own eBay account. This is a private seller account, not a business or storefront. The application does not offer sign-in to other eBay members, does not serve other sellers, and does not collect anyone's eBay username or password.

What is accessed

Using the operator's own authorization, the application may access:

  • Inventory and offers — listings, SKUs, descriptions, photos, prices and quantities.
  • Account settings — business policies (payment, returns, shipping) and inventory locations.
  • Order fulfilment — orders placed against the operator's listings, including the buyer's name and shipping address, strictly to pack, ship and support that order.
  • Marketing — the operator's own promotions and campaigns on their listings.
  • Public catalogue data — active listings from eBay's public search, used to research pricing.

Why

Only to list the operator's own second-hand items and to ship what sells. The data is not used for advertising, not used to train models, not sold, not rented, and not shared with anyone else.

Buyer information

Note on third-party data

When someone buys one of the operator's items, eBay supplies the buyer's name and delivery address so the order can be shipped. That information is used only to fulfil and support that order, is kept only as long as needed for shipping, returns, tax and accounting obligations, and is never used for marketing or disclosed to anyone beyond the carrier and authorities where required by law.

How credentials and data are stored

  • OAuth tokens are stored in a permission-restricted file on the operator's own machine. They are excluded from version control and are never published.
  • Listing records are stored locally on operator-controlled systems.
  • The application requests only the API scopes it needs to list items and fulfil orders.

Withdrawing access

Authorization can be revoked at any time from My eBay → Account settings → Sign in and security → Third-party app access. Revoking access immediately stops the application from acting on the account. Tokens also expire on their own and must be renewed.

04If you bought something

You can ask what information is held about you, ask for it to be corrected, or ask for it to be deleted once it is no longer needed for shipping, returns or tax records. Just email the address below and it will be sorted out.
